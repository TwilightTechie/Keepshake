# Keepshake V1 enclosure CAD

These are the original STEP exports shared for the first wearable Keepshake enclosure:

| File | Part |
| --- | --- |
| [`Top_Lid.step`](Top_Lid.step) | Top lid |
| [`Tub_VarA_NATO.step`](Tub_VarA_NATO.step) | Tub, NATO strap variant |
| [`Tub_VarB_QuickRelease.step`](Tub_VarB_QuickRelease.step) | Tub, quick release variant |

The files are provided for inspection and iteration. They represent an early prototype, not a production-ready mechanical specification. Check clearances, assembly, print orientation, and fit before fabrication. The website's interactive exploded illustration is a separate visual explanation and should not be used as a dimensional reference.
