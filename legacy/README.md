# Archived material

This directory holds retired prototypes and bench experiments retained for
reference. It is not part of the supported Keepsake capture or server deployment
path. Start with the repository root README for the current firmware, iPhone app,
and server layout.

Historical experiment files may describe old sample rates, endpoints, or firmware
and should not be used as current setup instructions. Private recordings, transcripts,
credentials, and vendor UF2 images are intentionally excluded from this archive.
